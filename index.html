      How to set it as your lock screen
      • iPhone / iPad: save to Photos → open the image → Share → Use as Wallpaper → Lock Screen.
      • Android: open the image in Gallery → ⋮ → Set as wallpaper → Lock screen.
      • Windows: Settings → Personalisation → Lock screen → Picture → Browse.
      • Mac: System Settings → Wallpaper → Add Photo.
      • Always live: tap Live lock screen at the top for a full-screen, second-by-second countdown on any device.
